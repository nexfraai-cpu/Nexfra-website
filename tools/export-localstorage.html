Nexfra ERP — LocalStorage Export Tool

Reads the ERP state out of this browser's localStorage and downloads it as a JSON file for import into PostgreSQL.

1. Detected Keys

KeySize
Only NEXFRA_* prefixed keys are exported. If no rows appear, open the frontend app once (so it writes state), then reload this page.

2. Export

The exported file is the wrapper object: { "storage": { "NEXFRA_ERP_STATE": {...}, "NEXFRA_AUTH_TOKEN": "true", ... } }. Import it with:

npm run migrate -- backend/../nexfra-legacy.json --dry-run
npm run migrate -- nexfra-legacy.json

3. Import to PostgreSQL

From backend/, run the migration CLI against the exported file:

tsx scripts/migrate.ts nexfra-legacy.json --dry-run  (validate only)
tsx scripts/migrate.ts nexfra-legacy.json  (write to PostgreSQL)

Warning: Ensure the Supabase schema migration has been applied and SUPABASE_URL / SUPABASE_SERVICE_KEY are configured in backend/.env.
